# Android 版との差（2026-11-12 時点）

Web 版の main（fc86f14、2026-11-03 の DM のリクエストまで）と、Android 版の main（a25f836、1.1.0 のあとの #164 まで）を照らし合わせた結果と、Web 版に入れる順番の案。
Android 版の PR は `petansayu/penyotter#番号`、Web 版のファイルは `src/lib/` からの場所で書く。

Web 版が前回そろえたのは Android 版の #136（DM のリクエスト）まで。そのあとに Android 版で入ったもの・消したもの、それより前で Web 版に入っていなかったものを並べる。

## A. Android 版で消したもの（Web 版にはまだある）

Android 版は 1.1.0 のあと、「使っていない機能を消したい」という利用者の希望で、次のものを消した（#160・#161）。**Web 版でも同じく消す**（利用者が決めた、2026-11-12）。ただし**カラム表示は Web 版では残す**（いったん消したあと「横長の画面でカラム表示は使えたほうがいい」と言われて戻した、同じ日）。

| 機能 | Android 版 | Web 版のいまの場所 |
|---|---|---|
| カラム表示 | #152 で作り、#155 で隠し、#160 でコードごと消した | `ui/Deck.svelte`・`DeckColumn.svelte`・`ColumnFeed.svelte`・`AddColumn.svelte`・`store/deck.svelte.ts`・`domain/deck.ts`（Web 版はカラムを 2026-10-21 から公開して使っている） |

## 入れる順番の案

PR はまとまりごとに分ける（どれも Web 版のテスト用リレーと使い捨ての鍵で確かめ、公開のリレーには送らない）。

1. **不具合・NIP のずれ**（B1。要確認の項目は確かめてから）。表示と送るイベントの中身が変わるもの。
2. **消すもの**（A。決まったものだけ）。
3. **リアクション・リポストへのリアクション・リポスト**（B2-1）と、投稿の「…」のまとめ（B2-3）。どちらも `NoteCard`・`ThreadView` を触るので続けて。
4. **ぺぇうさの「かすたむ」**（B2-2）。
5. **絵文字の登録・パック**（B2-4）。
6. **読み方・リレーセット・共有**（B2-5〜B2-7。決まったものだけ）。

それぞれ入れたら、Web 版の CLAUDE.md の該当の段落と、この資料の行を直す。
